
# RootService 🛠️

Welcome to the **RootService** repository! This project contains the core services for root login management in a system, allowing the root user to securely log into the system. The service connects to an **SQL Server** database for storing and retrieving login credentials.

## Description 🔐

RootService is a microservice designed for authenticating the root user into a system. This service is intended to ensure secure login capabilities and is optimized for ease of integration into larger systems. The system is powered by SQL Server, where all user credentials are securely stored.

### Core Features ⚙️
- **Root User Authentication:** Secure login for the root user, ensuring authorized access to the system.
- **SQL Server Database:** Credentials and user data are stored in SQL Server, ensuring reliable and scalable data management.
- **Microservice Architecture:** Designed as a microservice for easy integration into larger systems, allowing scalability and easy management.
- **Secure Connection:** Ensures that all communications are secure and that user data is protected.

## Technologies Used 🛠️

- **SQL Server:** The database used for storing root user credentials.
- **Microservices:** The system is based on a microservice architecture for easy scalability and integration.

This service can be integrated with other systems requiring root-level authentication for secure operations.
